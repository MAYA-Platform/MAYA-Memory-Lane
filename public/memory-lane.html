How It Works

Your memory is a chain of sealed records, not a chat log. Every session leaves a micro block, a sealed record with a SHA-256 fingerprint. Every six sessions, those micro blocks fold into one shelf block, so the library grows one shelf per six sessions instead of one file per session. Each shelf block carries the fingerprint of the block before it, so the whole history is linked. Change anything and the break is visible. The files are yours, stored on your machine, organized into shelves and volumes with a manifest, with no cloud middleman in the way. A single resume phrase pulls the whole library back when you need it. That's Memory Lane. You own the memory, the chain keeps it honest.
